Email Reply Generator – AI помощник для ответов в Gmail

Расширение для Chrome и Edge, которое добавляет кнопку генерации ответов прямо в интерфейс Gmail рядом с кнопкой "Отправить". 
Основано на ReactJS и Spring Boot, использует мощный AI Gemini для создания качественных ответов в разных стилях – от формального до дружеского. 
Просто откройте письмо, выберите нужный тон и получите готовый текст за секунды.
Для работы требуется только API ключ Gemini AI, который нужно добавить в конфигурацию. 
Запускается либо как веб-приложение через npm start, либо как расширение через стандартные команды Spring Boot.
Идеальное решение для быстрой обработки входящих писем без лишних усилий.
